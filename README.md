# GEOCHEM STP Intelligence

Frontend MVP for GEOCHEM ARABIA LIMITED — a B2B segmentation, targeting, and positioning workspace for the Saudi market.

## Stack

- Next.js (App Router)
- React + TypeScript
- Tailwind CSS
- Recharts

Supabase, authentication, and AI features are intentionally not included in this phase.

## Run locally

Requires Node.js 20+.

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).
